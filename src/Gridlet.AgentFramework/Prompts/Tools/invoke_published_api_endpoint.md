Send a request to one of this Gridlet's published GET endpoints and return the HTTP response as received, so you can show somebody exactly what it produces instead of describing it. The request is made as the person, so it can reach only what they can. Use parameter values you looked up with the query tool, never invented ones. GET endpoints only.

## name
The published endpoint's name, exactly as list_published_api_endpoints reports it.

## parameters
Query-string values as a flat JSON object, for example {"country":"Germany"}. Omit or pass {} when the endpoint takes no parameters.
