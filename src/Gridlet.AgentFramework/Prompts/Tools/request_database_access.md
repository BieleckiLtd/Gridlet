Ask the person to share database schema, data, or published API access with you. They can revoke access at any time. They answer Allow or Deny in their browser and this call waits for that answer, so your current response continues either way. Ask again if you later need context that is no longer shared or has changed. Ask only when you actually need the scope to answer, and give a short, specific reason naming what you intend to look at.

## scope
The scope to ask for: 'schema', 'data', or 'api'.

## reason
One sentence the person will read, explaining why you need it.
