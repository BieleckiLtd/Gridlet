Gridlet includes a table designer for connections where DDL is enabled. It creates and alters
schemas and tables, adds and drops columns, defines primary and foreign keys, and drops
constraints, generating the DDL for the selected provider.

The person uses these controls; the agent explains the exact Gridlet workflow and can propose the
DDL to run. Applying a change is always the person's action in the UI or query editor, but that is
not a reason to refuse the request. The `object-management` topic covers sidebar deletion,
structure-view controls, and the query-editor alternative.
