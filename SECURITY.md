# Security policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue. Use
[GitHub private vulnerability reporting](https://github.com/BieleckiLtd/Gridlet/security/advisories/new)
so the maintainers can investigate and coordinate a fix privately.

Include affected versions, reproduction steps, impact, and any suggested
mitigation. You can expect an initial acknowledgement within seven days.

## Supported versions

Security fixes are made against the latest published Gridlet release. Users
should upgrade to the newest available version to receive fixes.
